# sixteen-dev 🤖

A collection of AI experiments, agent frameworks, and developer tools. We explore the bleeding edge of autonomous agents — building, breaking, and sharing what we learn along the way.

## What We Build 🔨

- 🧠 **AI Agents** - Autonomous multi-agent systems that reason, plan, and execute complex tasks
- 🛠️ **Agent Tooling** - Infrastructure and utilities that make building agents faster and more reliable
- ⚡ **Experiments** - Rapid prototypes pushing the boundaries of what AI systems can do

## Projects 🚀

- **[openbell.ai](https://openbell.ai)** - AI-powered financial news platform that aggregates, analyzes, and delivers personalized market insights in real-time 📈
- **[OBaI](https://github.com/sixteen-dev/obai)** - Open-source multi-agent platform for stock research, strategy backtesting, and prediction market intelligence. A Central Hub dispatches 8 specialist agents in parallel (agents-as-tools) over custom MCP servers, with input guardrails and full observability via Opik tracing. [Read the blog post →](https://medium.com/gopenai/i-built-a-wall-street-research-desk-with-ai-agents-32ac9e0221eb) · [FAQ →](https://openbell.ai/obai/docs/faq) 🤖
- **[tomchat-app](https://github.com/sixteen-dev/tomchat-app)** - Talk to your computer. TomChat transcribes your voice directly into any application — entirely offline, entirely private 🎙️
- **[pyaibridge](https://github.com/sixteen-dev/pyaibridge)** - High-performance unified API library for multiple LLM providers, with automatic retry logic, cost tracking, metrics collection, and streaming support 🔗
